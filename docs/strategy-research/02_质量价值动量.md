# 质量价值动量

## 核心想法

用质量约束减少低估值陷阱，再用估值与价格动量寻找“基本面尚可、价格不过贵、市场开始认可”的股票。Fama–French 五因子包含盈利与投资因子；Novy-Marx 研究了毛利润相对总资产；AQR 的 Quality Minus Junk 将质量归纳为盈利、成长、安全和股东回报。它们提供研究依据，但不能直接照搬为 A 股个股买卖规则。

## 建议因子

```text
quality = 0.30 * rank(gross_profit / total_assets)
        + 0.25 * rank(roe_ttm)
        + 0.20 * rank(operating_cashflow / net_profit)
        + 0.15 * rank(-debt_to_assets)
        + 0.10 * rank(earnings_stability)

value   = 0.45 * rank(earnings_yield)
        + 0.35 * rank(book_to_price)
        + 0.20 * rank(sales_to_price)

score   = 0.40 * quality + 0.30 * value + 0.30 * momentum
```

亏损公司没有可比较的盈利收益率时，不应简单填 0 后参与排名；应单独过滤或使用行业内稳健缩尾。银行、券商等行业的资产负债结构不同，最好分行业标准化，或第一版暂时排除。

## 尚缺数据

当前数据库只有股票列表与日线行情。实施前需要新增独立表：

- `daily_basic_snapshots`：PE、PB、PS、总市值、流通市值、换手率等。
- `financial_indicators`：ROE、ROA、毛利率、负债率等，并保留报告期、公告日、更新标记。
- `income_statements`、`balance_sheets`、`cashflow_statements`：用于可复算的基础字段。

TUShare 官方接口可参考 [`daily_basic`](https://tushare.pro/document/2?doc_id=32)、[`fina_indicator`](https://tushare.pro/document/2?doc_id=79) 和 [`cashflow`](https://tushare.pro/document/2?doc_id=44)。具体积分权限和频率可能变化，接入前需按账号当前权限验证。

## 最关键的时点规则

财报只能从 `ann_date` 或实际可得日期开始使用。同一报告可能有快报、预告、更正和正式报告，必须定义优先级。回测查询应是“选股日之前最后一份已公开数据”，绝不能按报告期直接向后填充，否则会形成严重前视偏差。

## 回测重点

- 月度或季度调仓更符合财务数据频率，不建议每日全量换仓。
- 所有连续变量做 1%/99% 缩尾，再按行业和市值中性化做对照。
- 分别回测质量、价值、动量和三者组合，检查因子是否互补。
- 报告换手率、容量、行业暴露和小市值暴露，避免把收益错误归因于质量。
