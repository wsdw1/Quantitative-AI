# Piotroski F-Score 价值策略

## 核心想法

先从高账面市值比的价值股中选样本，再用九个财务信号判断盈利能力、财务杠杆/流动性和经营效率。每个条件满足记 1 分，总分 0–9。它更像“价值股质量筛选器”，不应脱离价值股票池单独包装成万能评分。

## 九项信号

| 分类 | 信号 | 记 1 分条件 |
| --- | --- | --- |
| 盈利 | ROA | 当期大于 0 |
| 盈利 | 经营现金流 | 当期大于 0 |
| 盈利 | ΔROA | 当期高于上年同期 |
| 盈利 | 应计质量 | 经营现金流 / 总资产高于 ROA |
| 杠杆 | Δ长期负债率 | 当期低于上年同期 |
| 流动性 | Δ流动比率 | 当期高于上年同期 |
| 融资 | 是否增发 | 过去一年未新增普通股 |
| 效率 | Δ毛利率 | 当期高于上年同期 |
| 效率 | Δ资产周转率 | 当期高于上年同期 |

## 项目实现建议

第一阶段只做年报版本，减少季节性比较和口径变化；选取低 PB 股票池中 `F-Score >= 7` 的标的，再加成交额与非 ST 过滤。第二阶段再测试中报/季报滚动版，但所有同比字段必须用相同报告期比较。

每个信号应同时保存布尔结果与原始分子分母。页面要能展开看到 9 项明细，避免只显示一个无法核查的整数。

## 数据难点

- 增发信号需要股本变动或融资事件，不能仅凭行情推断。
- 金融行业报表结构特殊，第一版建议排除。
- 合并报表口径、重述数据和更正公告会改变历史值，需要保留下载版本或更新时间。
- “公告当天是否可交易”要定义清楚；保守做法是下一交易日才允许使用。

## 回测重点

用年度调仓基线，比较 F-Score 0–3、4–6、7–9 三组，而不是只看一个阈值。报告价值股票池自身收益、F-Score 的增量收益、最大回撤、行业暴露与成交容量。
